# SimLive-Go — Project Summary

> Generated by `sdlc-ingest-project` skill. Read `io/out.md` for the standard format; this file is the human-readable summary.

## What it is
`simlive-go` is a simulated-live (24/7 linear) HLS playout system written in Go. It operates as a continuous pipeline:

- **Planner** (`PrepareSimlive`) — fetches EPG schedules from ESPX API, maps program items to `.ts` files via `rclone`, writes timeline metadata to Redis.
- **Engine** (`StartSimlive`) — reads mapped timelines from Redis, downloads `.ts` segments to a bounded sliding-window directory, stitches them into dynamic HLS playlists (`playlist.m3u8` + per-rung `playlist_<rend>.m3u8`), and serves video players.
- **API** (`cmd/api`) — REST surface for playout-channel CRUD (`/api/channels`), start/stop, and HLS delivery (`/live/{ch}/...`).

## What is supported
- Planner: per-channel EPG (today + tomorrow), stream-ID mapping, per-rung timeline ZSETs (`simlive:timeline:{ch}:{rend}`), ad insertion (`insertAdsIfNeeded`), quality-tier resolution (`SIMLIVE_QUALITY`), legacy-timeline flush, warm-pickup cron loop.
- Engine: 1-second tick loop, bounded on-disk window (`keepBehind` + window + ahead), shared segment cache (`{TMP_DIR}/{ch}/seg_N.ts`), PTS/DTS rewrite (`rewritePtsOffset`), SCTE-35 `#EXT-X-DATERANGE` + per-segment `#EXT-X-SCTE35`, `lookBehindSegment` for edge detection, master playlist with 3 `STREAM-INF` lines.
- API: channel management, Redis purge (`purgeChannelRedisData`), breaker counter (`planner:failures:{ch}`), HLS routes (master + per-rung media + shared `.ts` segments).
- Storage: `rclone cat` (manifest parsing), `rclone copyto` (segment download).
- Quality tiers: 360p / 720p / 1080p (VOD `L_0`/`L_1`/`L_2`; ads `L2`/`L1`/`L0`).
- Multi-rendition (M1.5): shared segment cache + 3 advertised rungs + `simlive:renditions:{ch}` metadata + `playlist_<rend>.m3u8` API shape. M2 (true per-rung separate segments) deferred.
