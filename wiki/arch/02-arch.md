## Key architecture invariants (from `.github/instructions/simlive-summary.instructions.md`)

- **Planner is SINGLE writer of `status='LIVE'`** (`markChannelLive` / `MarkChannelLiveForChannel`). Engine reconciler gates on `is_active=true AND status='LIVE'`.
- **Per-rung ZSETs** (`simlive:timeline:{ch}:{rend}`) — one per active rung (360p / 720p / 1080p). Score = `MediaStart` (seconds); member = `SegmentItem` JSON (incl. `pts_offset`, `rendition`, 4 ad-break fields `is_ad / ad_break_id / ad_break_start / ad_break_duration`, all omitempty).
- **M1.5 shared-cache ABR ladder** (`simlive:renditions:{ch}` metadata) — 3 advertised rungs via master playlist (`#EXT-X-STREAM-INF` + `#EXT-X-INDEPENDENT-SEGMENTS`). M2 (true per-rung separate `.ts` files) deferred.
- **Bounded on-disk window** — `SIMLIVE_KEEP_BEHIND` (5) + 5 + `SIMLIVE_DOWNLOAD_AHEAD` (5) = 15 `.ts` files per rung (default 45 total). Redis timeline window (`[-300s, +120s]`) queried for awareness; only active window downloaded/kept.
- **Warm start by default** — `PrepareEnv` preserves `{TMP_DIR}/{ch}/` across restarts. `ENABLE_CLEAN_UP=true` triggers cold start (`os.RemoveAll(tmpDir)`).
- **SCTE-35 emission** — per-rung media playlists emit `#EXT-X-DATERANGE` (CUE-OUT before first ad EXTINF; CUE-IN before first VOD EXTINF after break) + per-segment `#EXT-X-SCTE35` (`CUE="<base64>",TYPE=<segType>,ID="<adbreak-id>"`). `TYPE` = decimal `segmentation_type_id` (0x30 pre-roll, 0x34 slice-point, 0x35 cue-in). `DURATION` unquoted and trailing; capped at 3 decimal places.
- **Quality tiers (`SIMLIVE_QUALITY`)** — 360p (`L_0` VOD / `L2` ads), 720p (`L_1` / `L1`), 1080p (`L_2` / `L0`).
