## Summary

Create a standalone partner demo server at `./cmd/partner/main.go` to simulate a partner API when one isn't available. It provides simple token-based auth, serves minimal fixed-path endpoints for channels/EPG, and serves partner communication data files over HTTP for use with `ClientDownload`. Configuration should be simple (based on `partner.example.yaml`), reading demo data from files on disk.
